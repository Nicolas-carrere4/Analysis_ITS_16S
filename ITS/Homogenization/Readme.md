Multivariate homogeneity of dispersion was first estimated using beta-dispersion analysis (betadisper) applied to Aitchison distance matrices calculated from CLR-normalized community data. For each compartment separately, distances of individual samples to their corresponding land-use centroid were extracted and analysed using linear mixed-effects models, with land use included as a fixed effect and neighborhood as a random intercept to account for the spatial structure of the sampling design. Model assumptions were evaluated using DHARMa simulated residual diagnostics. Pairwise differences among land-use types were subsequently assessed using estimated marginal means with multiple-comparison correction.
