ECM alpha diversity was assessed using the Shannon diversity index calculated from ECM-only fungal communities within each sample. ASVs were assigned to ecological functions using the FungalTraits database based on genus-level taxonomy, and only taxa annotated as ectomycorrhizal were retained for this analysis. To reduce biases associated with uneven sequencing depth, samples were rarefied within each compartment (Leaf, Root, Soil) prior to diversity estimation.
The effect of land use on ECM Shannon diversity was tested separately for each compartment using non-parametric Kruskal–Wallis tests, followed by Dunn post-hoc comparisons with Benjamini–Hochberg correction for multiple testing. A non-parametric approach was preferred because diagnostic analyses of linear mixed-effects models indicated substantial deviations from normality assumptions, making Gaussian models inappropriate for these data. Unlike parametric linear models, Kruskal–Wallis tests do not require normally distributed residuals and are therefore more robust for skewed ecological diversity data.
Significance patterns were visualized using compact letter displays derived from Dunn post-hoc comparisons.
