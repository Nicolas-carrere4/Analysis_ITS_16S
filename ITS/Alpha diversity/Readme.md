Fungal alpha diversity was assessed using the Shannon diversity index calculated from rarefied ITS datasets. Rarefaction was performed independently for each compartment (Leaf, Root, Soil) using the minimum sequencing depth observed within each subset in order to reduce biases associated with unequal sequencing depth among samples.
Alpha diversity analyses were conducted on the full fungal community without functional filtering. For each compartment, differences in Shannon diversity among land-use types were tested using Kruskal–Wallis rank-sum tests, followed by pairwise Dunn tests with Benjamini–Hochberg correction for multiple comparisons.
Results were visualized using boxplots displaying the distribution of Shannon diversity values across land-use categories, with compact letter displays indicating significant pairwise differences among groups.
