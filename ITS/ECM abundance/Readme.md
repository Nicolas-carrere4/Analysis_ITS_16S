Functional composition of fungal communities was inferred using the FungalTraits database. For ECM analyses, ASVs were classified as either ectomycorrhizal fungi (ECM) or Other fungi based on lifestyle annotations. For pathogen analyses, all ASVs associated with pathogen-related lifestyles (i.e., containing the term “patho” in the FungalTraits annotation) were grouped as All pathogens. ASV abundances were aggregated at the guild level and analyzed using centered log-ratio (CLR) transformation computed with ALDEx2 to account for the compositional nature of metabarcoding data. For each compartment (Leaf, Root, Soil), the effect of land use on guild abundance was tested using linear mixed-effects models (LMMs), with Landuse as a fixed effect and Neighborhood as a random effect. Pairwise comparisons were performed using estimated marginal means (emmeans) with Sidak-adjusted p-values, and significance was visualized using compact letter displays.
