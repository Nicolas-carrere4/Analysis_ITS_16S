Soil fungal community composition was assessed using Non-metric Multidimensional Scaling (NMDS) based on Aitchison distance matrices calculated from centered log-ratio (CLR)-transformed sequencing data, in order to account for the compositional nature of metabarcoding datasets. Analyses were restricted to soil samples, where environmental measurements were available.
NMDS ordination was performed in three dimensions (k = 3) to improve representation of complex community dissimilarities, and two-dimensional projections of the ordination were visualized using the first two NMDS axes. Stress values were used to evaluate ordination quality. Samples positioned closer together in ordination space represent more similar fungal community compositions.
To identify environmental and functional gradients associated with community turnover, environmental variables (temperature, moisture, pH, soil organic matter, and nutrient concentrations) as well as fungal guild abundances were fitted onto the ordination using permutation-based vector fitting (envfit). Fungal guilds included ectomycorrhizal fungi (ECM), plant pathogens, animal parasites, and saprotrophs, as defined using the FungalTraits database. Guild abundances were calculated from ASV counts aggregated at the guild level and transformed using centered log-ratio (CLR) transformation prior to analysis.
Vector direction indicates the orientation of increasing values for each variable across the ordination space, whereas vector length reflects the strength of association with fungal community structure. Statistical significance of fitted variables was assessed using permutation tests (999 permutations), and only significant vectors were retained for visualization.
