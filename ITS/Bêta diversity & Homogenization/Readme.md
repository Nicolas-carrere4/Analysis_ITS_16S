Community composition was assessed using Aitchison distance calculated from CLR-transformed ITS data. Differences in fungal community composition were tested using PERMANOVA with permutations restricted within Tree_ID. Multivariate dispersion was assessed using betadisper to evaluate differences in within-group variability.


Multivariate homogeneity of dispersion was assessed using beta-dispersion analysis (betadisper) applied to Aitchison distance matrices. Differences in dispersion among land-use types were tested using both ANOVA and permutation tests (999 permutations). Pairwise differences were subsequently evaluated using Tukey’s HSD post-hoc tests.
