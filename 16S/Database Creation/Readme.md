A bacterial functional annotation database was constructed by combining information from multiple published sources. Functional assignments included broad ecological strategies and metabolic functions, including nitrogen cycling pathways, cellulolytic activity, methanotrophy, copiotrophy, oligotrophy, and other literature-derived functional groups. Taxonomic names were standardized at the genus level, duplicate entries were merged, and functional annotations from all sources were combined into a single taxon-to-function reference database used for downstream analyses.
