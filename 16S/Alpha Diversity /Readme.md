Bacterial alpha diversity was assessed using the Shannon diversity index calculated from rarefied 16S datasets. Rarefaction was performed independently for each compartment (Leaf, Root, Soil) using the minimum sequencing depth observed within each subset to reduce biases associated with unequal sequencing depth among samples.

Alpha diversity analyses were conducted on the full bacterial community without functional filtering. For each compartment, differences in Shannon diversity among land-use types were tested using Kruskal–Wallis rank-sum tests. Pairwise differences among land-use categories were evaluated using Dunn tests with Benjamini–Hochberg correction for multiple comparisons.

Results were visualized using boxplots showing the distribution of Shannon diversity values across land-use categories, together with individual samples, group means, and compact letter displays summarizing significant pairwise differences among groups.
