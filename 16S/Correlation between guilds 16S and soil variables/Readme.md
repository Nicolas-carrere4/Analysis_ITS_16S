To assess whether bacterial functional guilds were associated with soil physicochemical conditions, Spearman correlations were calculated between guild-level CLR abundances and soil environmental variables. Analyses were restricted to soil samples, as environmental measurements were soil-based. For each functional guild, CLR-transformed abundances obtained from the ALDEx2-based guild analysis were matched with soil temperature, moisture, pH, SOM, NH4, NO3, and Olsen phosphorus using Tree_ID.

Spearman rank correlations were calculated separately for each guild–environment variable combination. P-values were adjusted for multiple testing using the Benjamini–Hochberg false discovery rate correction. Results were visualized as a heatmap showing Spearman’s rho values, with significance levels indicated after multiple-test correction.
